# 技术指标综合解读框架

> 用于 v0.0.8-basic 基础版技术形态分析 Skill 的指标解读指导。
> 核心思想：从"指标罗列"升级为"维度叙事"——先判断各维度内部一致性，再做跨维度交叉验证。

---

## 一、五维分析框架

将技术指标分为五个维度，每个维度内部包含多个指标。先判断维度内部是否一致，再与其他维度做交叉验证。

### 维度 1：趋势方向

**包含指标**：MA5/10/20/60 排列、MACD（DIF/DEA/柱体）

**解读逻辑**：

```text
多头排列（MA5>MA10>MA20>MA60，价格站上全部均线）
  → 趋势向上，回调即是机会

空头排列（MA5<MA10<MA20<MA60，价格跌破全部均线）
  → 趋势向下，反弹即是压力

震荡整理（均线纠缠或价格在中短期均线之间）
  → 方向不明，观望或区间操作
```

**MACD 配合**：
- 多头排列 + MACD 金叉 + 柱体扩大 → 趋势确认，动能增强
- 多头排列 + MACD 死叉 → **顶背离风险**，趋势可能放缓
- 空头排列 + MACD 死叉 + 柱体扩大 → 下跌趋势确认
- 空头排列 + MACD 金叉 → **底背离机会**，下跌动能衰竭

---

### 维度 2：动量强度

**包含指标**：RSI(6/12/14)、KDJ(K/D/J)

**解读逻辑**：

```text
RSI 超买（>70）
  → 短期上涨过快，注意回调风险
  → 若 RSI 高位但价格仍在涨 = 动能仍在，但脆弱
  → 若 RSI 高位且价格走平 = 顶背离，动能衰竭

RSI 超卖（<30）
  → 短期下跌过猛，注意反弹机会
  → 若 RSI 低位但价格仍在跌 = 恐慌抛售，可能还有一跌
  → 若 RSI 低位且价格走平 = 底背离，反弹在即

RSI 中性（30~70）
  → 无极端情绪，趋势可以延续
```

**KDJ 配合**：
- RSI 超卖 + KDJ 金叉（K 上穿 D，J 从负值区回升）→ 反弹信号较强
- RSI 超买 + KDJ 死叉（K 下穿 D，J 进入超买区后回落）→ 回调信号较强
- K 与 D 差距过大（如 K=80, D=40）→ J 会极高，说明短期波动剧烈
- J < 0 或 J > 100 → 极端状态，但可能持续，不宜单独作为反转信号

---

### 维度 3：波动状态

**包含指标**：BOLL（上轨/中轨/下轨）、ATR(14)

**解读逻辑**：

```text
BOLL 位置：
  价格在上轨附近 → 短期偏强，但触及压力
  价格在中轨附近 → 多空平衡，方向待定
  价格在下轨附近 → 短期偏弱，但触及支撑

BOLL 宽度（带宽 = (上轨-下轨)/中轨）：
  带宽收窄 + ATR 低位 → 波动收敛，即将选择方向（"暴风雨前的宁静"）
  带宽扩大 + ATR 高位 → 波动加剧，趋势进行中

ATR 分位：
  ATR 历史低位（<20%分位）→ 波动率极低，警惕方向突破
  ATR 历史高位（>80%分位）→ 波动率极高，警惕反转或延续
```

**趋势与波动的配合**：
- 趋势向上 + BOLL 带宽扩大 → 上涨趋势健康，动能充足
- 趋势向上 + BOLL 带宽收窄 → **上涨动能衰竭**，可能进入整理
- 震荡整理 + BOLL 带宽收窄 → 即将选择方向，等待突破
- 价格突破 BOLL 上轨 + ATR 放大 → 突破有效概率较高
- 价格突破 BOLL 上轨 + ATR 萎缩 → **假突破概率较高**

---

### 维度 4：量价配合

**包含指标**：成交量、OBV、AD（累积/派发线）、MFI、量比

**解读逻辑**：

```text
上涨中的量价关系：
  价涨量增 → 资金流入，上涨健康
  价涨量缩 → 上涨乏力，可能背离
  价涨 + OBV 创新高 → 资金持续流入，趋势确认
  价涨 + OBV 走平/下降 → **量价背离**，警惕见顶

下跌中的量价关系：
  价跌量增 → 恐慌抛售，可能见底或加速
  价跌量缩 → 抛压减轻，可能企稳
  价跌 + OBV 走平/上升 → 资金在低位承接，可能筑底

量比判断：
  量比 > 1.5 → 成交活跃，关注是否有重大信号
  量比 < 0.7 → 成交清淡，信号可靠性降低
```

**与趋势维度的交叉**：
- 趋势向上 + 量价齐升 → 最健康的上涨结构
- 趋势向上 + 价涨量缩 → **动能衰减**，注意趋势放缓
- 震荡整理 + 放量突破 → 突破有效性较高
- 震荡整理 + 缩量突破 → 假突破风险大

---

### 维度 5：极端值预警

**包含指标**：所有指标的历史分位数（252日回看）

**解读逻辑**：

```text
单一指标极端：
  历史分位 < 5% 或 > 95% → 统计意义上的罕见状态
  → 不意味着必然反转，但意味着"当前状态在历史上不常见"
  → 结合趋势判断：趋势中的极端可能持续，震荡中的极端更容易回归

同类指标共振（2+ 同时极端）：
  多个动量指标同时超买 → 系统性过热，回调风险累积
  多个动量指标同时超卖 → 系统性超卖，反弹概率增加
  多个成交量指标同时高位 → 资金活跃，关注方向选择

跨类别极端组合：
  动量超买 + 成交量高位 → 动能过热，顶部区域特征
  动量超卖 + 成交量萎缩 → 市场低迷，底部区域特征
  ATR 低位 + 成交量萎缩 → 极度低迷，即将变盘
```

**重要提醒**：历史分位是**描述性工具**（"当前状态在历史上有多罕见"），不是**预测性工具**（"接下来会不会反转"）。极端状态可以持续很久，尤其在强趋势中。

## 二、跨维度交叉验证矩阵

| 组合 | 状态 | 含义 |
|---|---|---|
| 趋势↑ + 动量↑ + 波动↑ | 三维度共振向上 | 强趋势，动能充足 |
| 趋势↑ + 动量↓ + 波动↓ | 顶背离结构 | 趋势可能放缓或反转 |
| 趋势↓ + 动量↓ + 波动↑ | 三维度共振向下 | 强下跌，恐慌释放 |
| 趋势↓ + 动量↑ + 波动↓ | 底背离结构 | 下跌动能衰竭，关注反弹 |
| 趋势→ + 动量↓ + 波动↓ | 震荡下行 | 弱势整理，偏空 |
| 趋势→ + 动量↑ + 波动↓ | 震荡蓄势 | 整理末期，关注向上突破 |
| 波动↑ + 量价↑ | 放量突破/下跌 | 方向选择中，有效性较高 |
| 波动↓ + 量价↓ | 缩量整理 | 观望，等待信号 |

## 三、汇报叙事模板

基于五维框架，向用户汇报时应按以下结构组织：

```
【趋势判断】{多头排列/空头排列/震荡整理}
  → {具体描述：价格相对均线位置 + MACD 状态}

【动量状态】{超买/超卖/中性}
  → RSI={x}（{状态}），KDJ {金叉/死叉}
  → {若存在背离："注意：价格与动量出现背离"}

【波动环境】{扩张/收敛/常态}
  → BOLL带宽{宽/窄}，价格位于{上轨/中轨/下轨}附近
  → ATR={x}（历史{x}%分位），{波动放大/收敛/常态}

【量价关系】{量价齐升/量价背离/缩量整理}
  → {成交量状态 + OBV/AD 状态}

【综合研判】
  {将以上四个维度综合，给出一段连贯的叙事：
   "当前处于XX状态，趋势方向XX，动量XX，波动XX，量价XX。
    主要风险点是XX，需关注的关键价位是XX。"}
```

## 四、国债期货的特殊考量

国债期货（T0/TF0/TS0）波动率远低于股票，解读时需注意：

1. **RSI 中性区间更窄**：债券日波动小，RSI 很少进入严重超买超卖（>75/<25 即可视为极端）
2. **均线纠缠常态化**：短期均线差值常以 0.0x 为单位，均线"多头排列/空头排列"不如股票明确
3. **BOLL 带宽极窄**：正常带宽可能只有 0.5%~1%，突破上轨即算显著偏离
4. **量比意义不同**：国债期货流动性极好，量比大幅波动往往反映宏观事件而非技术面
5. **MACD 柱体微小**：柱体绝对值常以 0.0x 为单位，金叉/死叉的"视觉显著性"低，需结合价格行为判断

## 五、避免常见解读误区

1. **不要把单一指标当圣旨**：MACD 金叉不代表必涨，RSI 超买不代表必跌
2. **不要预测方向**：解读框架描述的是"当前状态"，不是"接下来会怎样"
3. **不要忽视时间框架**：日线 RSI 超卖，但周线可能仍然中性
4. **不要机械套用阈值**：国债期货的"超买"和股票的"超买"标准不同
5. **分位数不等于概率**：历史分位 1% 不代表"99%概率会反弹"
