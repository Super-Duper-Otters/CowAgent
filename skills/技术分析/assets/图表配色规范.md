# 图表配色与绑图规范

## 配色方案

### K线颜色（中国市场惯例：红涨绿跌）
- 上涨（close ≥ open）：`#E53935` / `#F44336`（**红色**，对应"看涨/阳线/多头"）
- 下跌（close < open）：`#43A047` / `#26A69A`（**绿色**，对应"看跌/阴线/空头"）

> **重要**：本 skill 全部遵循中国 A 股/期货市场颜色惯例（红涨绿跌），与欧美市场（绿涨红跌）相反。
> Markdown 报告中：🔴 = 看涨形态，🟢 = 看跌形态。

### 均线颜色
| 均线 | 颜色代码 | 用途 |
|------|---------|------|
| MA5 | `#2196F3`（蓝） | 短期趋势 |
| MA10 | `#FF9800`（橙） | 中期趋势 |
| MA20 | `#9C27B0`（紫） | 中长期趋势 |
| MA60 | `#795548`（棕） | 长期趋势 |
| BOLL线 | 灰色虚线 | 布林带 |

### 指标面板配色
- MACD 柱（红/多头）：`#E53935` / `#F44336`
- MACD 柱（绿/空头）：`#43A047` / `#26A69A`
- MACD线：`#2196F3`
- Signal线：`#FF9800`
- K：`#2196F3`，D：`#FF9800`，J：`#9C27B0`

## 图表规格

### 主图（4面板）
- 尺寸：16×14 英寸
- 面板高度比：3.5 : 1.0 : 1.0 : 1.0
- 分辨率：150 DPI
- 背景：白色（`facecolor='white'`）

### 形态详图
- 尺寸：10×5.5 英寸
- 展示窗口：±12 根K线

### 高级形态图
v0.0.8-basic 不生成高级形态图。若后续恢复波段结构、W底/M顶、头肩、三角形/楔形/旗形等高级形态模块，再单独补充该部分规范。
