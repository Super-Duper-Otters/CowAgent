# 投资业务后台运营工作台实施计划

**Goal:** 把投资业务后台从基础表单和长表格改造成运营可用的工作台。

**Architecture:** 后端只补 `daily-content` 的 `current_effective` 契约；页面结构继续在 `channel/web/static/js/console.js` 中按现有模式渲染；样式集中补到 `channel/web/static/css/console.css`。不改通用 Web 控制台框架。

**Tech Stack:** Python 3.12, web.py, SQLAlchemy, vanilla JS, CSS, pytest, node syntax check, in-app Browser verification.
