# 投资技术分析缓存配置

技术分析缓存会在收盘后做软失效检查，默认检查时间为北京时间 `15:30`。可在 `config.json` 或投资配置表中设置：

```json
{
  "investment.technical_analysis.cache_close_invalidate_time": "15:30"
}
```

该值只接受 `HH:MM` 格式。配置缺失或格式非法时，系统回退到默认值 `15:30`，不影响用户查询。

注意事项：

- 该时间始终按北京时间 `Asia/Shanghai` 理解。
- 该逻辑不是交易日历校验，周末和节假日不会额外做自然日强制判断。
- 数据源收盘后延迟更新时，系统仍以行情源实际返回的最新日线日期作为 `market_date`，不会强制切换到自然日。
- 该配置只影响技术分析缓存策略，不影响利率、转债、后台上传内容或通用缓存读写函数。
